## 4. S4 位移-力数据集

- **帧数 55**（`disp-00000` … `disp-00054`）
- **平衡帧（disp-00000）残余力 max|F| = 0.000933 eV/Å**（144 原子超胞）
  - 对比：Mn₂In₂Se₅ 旧 3×3×3 数据集（`equilibrium_max_force`）为 0.1031 eV/Å，即本协议把平衡帧残余力压低了约 **110 倍**。
- 超胞：**32 Mn + 32 In + 80 Se = 144 原子**（`SPOSCAR`）
- 自旋 / DFT+U（继承自 S1，与弛豫同一势能面）：
  - `ISPIN = 2`，`MAGMOM = 32*5 112*0`（32 个 Mn 取 5 μB，其余 112 个原子取 0）
  - `LDAU = .TRUE.`，`LDAUTYPE = 2`，`LDAUL = 2 -1 -1`，`LDAUU = 4 0.0 0.0`，`LDAUJ = 0.0 0.0 0.0`
  - `LMAXMIX = 4`
- 取力精度设置（S4 INCAR 原文）：`ISYM = 0`（勿对称化力）、`PREC = Accurate`、`ENCUT = 410`、
  `EDIFF = 1E-7`、`LREAL = .FALSE.`、`ADDGRID = .TRUE.`、`LASPH = .TRUE.`、`ALGO = Normal`、
  `NELM = 200`、`NELMIN = 6`、`ISMEAR = 0`、`SIGMA = 0.05`、`IBRION = -1`、`NSW = 0`、`NCORE = 4`、`KPAR = 8`
