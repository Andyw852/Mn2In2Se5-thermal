## How to read the figures

- **The rightmost point is the largest cutoff the 4×4×1 cell allows** (6.45 Å for
  MnIn₂Se₄, 6.51 Å for Mn₂In₂Se₅). Both curves are still falling there, so
  neither component is cutoff-converged — the figures show the trend, not a
  converged value.
- **κ_zz plots the "rest of the zone" term, never the total.** The total is
  dominated by the single first Γ–Z q-point (40 % of it at these meshes) and
  moves with the mesh; only the rest term is physical.
- **The κ_zz coherence is grey and must not be added to the rest term.** It was
  measured on the contaminated total, so it only shows that the coherence term
  itself is nearly cutoff-independent.
- **In-plane curves**: total = population + coherence. The coherence is flat
  (in-plane +2.4 % over the whole range for MnIn₂Se₄) while the population falls
  by 30 %, i.e. the cutoff problem is a population problem.
