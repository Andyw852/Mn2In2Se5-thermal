# test/figures — index

**Use `paper/` for the manuscript.** It holds the three figures on one
consistent convention (κ_zz mesh-converged, as in REPORT §9.1), generated by one
script.

| directory / file | status | why |
|---|---|---|
| `paper/` | **current** | fig1 κ(T), fig2 calc vs experiment, fig3 cutoff |
| `kappa_vs_T/MnIn2Se4_kappa_vs_T`, `Mn2In2Se5_kappa_vs_T`, `both_kappa_vs_T` | consistent, superseded by `paper/fig1` | same data and convention (rest term); no quoted-value markers |
| `kappa_vs_T/vca_vs_T` | consistent, folded into `paper/fig2` | 20³ ordered/VCA pairs, rest term |
| `kappa_vs_T/theory_vs_exp*` | **superseded** | default `--source m30-total` plots 30³ totals, which carry the Γ–Z artifact (+15–25 % on κ_zz) |
| `calc_vs_experiment/calc_vs_experiment` | **superseded** for the L1 lines | L1 lines are 30³ totals. The L3 curves and `extrinsic_*.json` are still used, by `paper/fig2` |
| `cutoff/*` | data still used, by `paper/fig3`; figures superseded | the figures overlay the 4.4.0 SMM19 coherence term (wrong for MnIn₂Se₄, report §7) |
| `scattering/` | unchanged | scattering-rate comparison, not part of this convention question |

Data caveats:

- `kappa_vs_T/data_*_m30.json` store the **30³ totals under the key
  `kzz_rest`**. The name is misleading; see each file's `convention` field.
- `cutoff/data_*.json` `kzz_coherence` / `inplane_coherence` are 4.4.0 SMM19
  values. For MnIn₂Se₄ they are not usable (report §7).
