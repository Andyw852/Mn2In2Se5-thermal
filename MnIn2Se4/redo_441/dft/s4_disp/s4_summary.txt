System: MnIn2Se4, R-3m (#166), 7-atom primitive cell (Mn1 In2 Se4); after the basis change
the 4x4x1 supercell has 112 atoms
DFT: VASP, PBE-D3 (IVDW=11) + U(Mn)=4 eV, ISPIN=2, FM (MAGMOM = 16*5 96*0),
     PREC=Accurate, EDIFF=1E-7, ISYM=0, NCORE=4, KPAR=2, 48 cores (jzzn cpu192, qos regular)

     n_disp=45, rattle_std=0.005477, displacement RMS 0.01745 A (max 0.0688 A), cut3 candidates

## Frame list and quality

disp-00000 = equilibrium reference frame, disp-00001..00045 = 45 displaced frames, 46 frames in
total, all converged (OUTCAR contains "aborting loop because EDIFF is reached").

- equilibrium-frame residual force: max|F| = 0.000508 eV/A (threshold 0.005) -> clean structure
- displaced frames: max|F| 0.620-0.827 eV/A, RMS 0.259-0.289 eV/A (normal magnitude)
- total magnetisation (all 46 frames): 79.74994-79.74999 muB/cell, target 16 x 4.9844 = 79.750,
  deviation < 1e-4 -> the displacements did not trigger an occupation/magnetisation jump, so the

- per-frame energy / maximum force / RMS force / magnetisation: see frame_summary.csv;
  raw forces and structures in disp-*/vasprun.xml (this repo does not track OUTCAR by the

## How this dataset was used later (important)

This 4x4x1 dataset was used for a pheasy-gpu two-method force-constant fit (RFE-OLS primary +
ALASSO secondary, see fit_4x4x1/). Both fits have good force residuals (RMSE 0.88 / 0.84 meV/A,
relative 0.58% / 0.55%, fc2 symmetry spread 5e-9), yet **both fail the imaginary-frequency gate**:

  near-Gamma acoustic branch (branch 0), q = (-0.0357, 0, 0.0357), |q| ~ 0.05
  min freq = -0.1388 THz = -4.63 cm-1 (no-NAC -0.151 THz), 145 negative-frequency q points

The harmonic parts of the two methods are identical and the results almost the same, so the
problem lies in fc2, not in the fitting method. The dispersion shows: the three acoustic branches
at Gamma are ~0 (ASR fine), but the lowest TA branch is negative over |q| ~ 0.03-0.12 and only
turns positive at 0.15 -> a broad soft mode with an effectively negative elastic constant.

**Cause (corrected 2026-11-10)**: it is not the supercell size. The 4x4x1 cell is >= 13.2 A thick
in all three directions (safe cutoff 6.50 A), wider than the old 3x3x3 rhombohedral supercell at
about 10.5 A (safe cutoff 5.17 A); Mn2In2Se5 is stable with the same 4x4x1 setup.
The two real causes are:

1. **The fit has no rotational invariance / Huang equilibrium condition** (PHEASY_RASR=auto
   resolves to none for a bulk system).
   Three acoustic branches at zero at Gamma only proves that the translational sum rule is
   satisfied; the TA branch going negative at |q| ~ 0.03-0.12 is exactly the typical signature of
   this missing constraint.
2. **The equilibrium frame (disp-00000) carries about -1.23 kBar of isotropic residual stress**
   (diagonal -1.246 / -1.246 / -1.207 kBar, deviatoric part < 0.03 kBar), from the Pulay stress
   difference between the S1 relaxation with ENCUT=540 and the S4 force evaluation with 410;
   this is the same physics as the Huang condition and likewise softens the long-wavelength
   acoustic branches (it cannot explain -0.14 THz on its own, but it contributes).

**Disposition**: keep this dataset - it is the only force dataset for this material computed with
the same DFT settings as Mn2In2Se5 (PBE-D3 + U4 + FM). The fit is redone on the same 4x4x1 data
with **PHEASY_RASR = H** (Huang constraint).
If negative frequencies below -0.05 THz near Gamma persist with RASR=H, the next step is to
recompute the equilibrium frame (single frame) with ENCUT=540 to decide whether the residual
stress is the main cause, and only then whether S4 needs a new setting and a rerun.
(Note: the 3x3x3 / 189-atom data in datasets/MnIn2Se4_raw is the test dataset shipped with
pheasy, its DFT settings are unknown, and it must not be used for results of this material.)
