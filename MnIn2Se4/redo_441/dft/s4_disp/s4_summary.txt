体系：MnIn2Se4，R-3m (#166)，7 原子原胞（Mn1 In2 Se4），换基矢后 4x4x1 超胞 = 112 原子
DFT：VASP，PBE-D3（IVDW=11）+ U(Mn)=4 eV，ISPIN=2，FM（MAGMOM = 16*5 96*0），
     PREC=Accurate，EDIFF=1E-7，ISYM=0，NCORE=4，KPAR=2，48 核（jzzn cpu192，qos regular）
KPOINTS：超胞 Gamma 2x2x2（等效原胞 8x8x2，来自 S1-S3 的 8x8x2 设置）
位移：AutoZT kl-dft-cpu S4_disp，alm/rattle 随机位移，disp_plan.json 记录 n_disp=45、
     rattle_std=0.005477、displacement RMS 0.01745 A（最大 0.0688 A）、
     cut3 候选 4.30/4.71/5.00/5.60/6.23/6.45 A，4x4x1 超胞安全截断 6.50 A

disp-00000 = 平衡参考帧，disp-00001..00045 = 45 个位移帧，共 46 帧，全部收敛
（OUTCAR 有 "aborting loop because EDIFF is reached"）。

- 平衡帧残余力：max|F| = 0.000508 eV/A（阈值 0.005）→ 结构干净

  偏差 < 1e-4 → 位移没有触发占据/磁矩跳变，力可信

## 这批数据后来怎么用的（重要）

用这批 4x4x1 数据做了 pheasy-gpu 双方法力常数拟合（RFE-OLS 主 + ALASSO 副，见
fit_4x4x1/），两次拟合力残差都很好（RMSE 0.88 / 0.84 meV/A，相对 0.58% / 0.55%，
fc2 对称性 spread 5e-9），但**虚频闸都不过**：

  近 Gamma 声学支（branch 0），q = (-0.0357, 0, 0.0357)，|q| ~ 0.05
  min freq = -0.1388 THz = -4.63 cm-1（no-NAC -0.151 THz），145 个负频 q 点

两种方法的谐波部分相同、结果几乎一样，说明问题在 fc2 而不在拟合方法。测色散显示：
Gamma 点三支声学 ~0（ASR 正常），但最低 TA 支在 |q| ~ 0.03-0.12 整段为负、到 0.15 才回正
→ 等效弹性常数偏负的大范围软模。

**原因（2026-11-10 更正）**：不是超胞大小。4x4x1 三个方向的垂直宽度都 >= 13.2 A（安全截断 6.50 A），
比旧 3x3x3 菱方超胞的约 10.5 A（安全截断 5.17 A）更宽；Mn2In2Se5 用同一套 4x4x1 是稳定的。
真正的两个原因是：

1. **拟合没加转动不变性 / Huang 平衡条件**（PHEASY_RASR=auto 在 bulk 解析成 none）。
   Gamma 点三支声学为 0 只说明平移求和规则满足；|q| ~ 0.03-0.12 的 TA 支为负，
   正是这类约束缺失的典型表现。
2. **平衡帧（disp-00000）有约 -1.23 kBar 的各向同性残余应力**（对角 -1.246 / -1.246 / -1.207 kBar，
   偏量 < 0.03 kBar），来自 S1 用 ENCUT=540 弛豫、S4 用 410 取力的 Pulay 应力差；
   与 Huang 条件管的是同一件事，同样会让长波声学支变软（单靠它解释不了 -0.14 THz，但会推一把）。

**处置**：这批数据保留——它是本材料唯一一套与 Mn2In2Se5 同 DFT 设置（PBE-D3 + U4 + FM）的
力数据集。拟合改用 **PHEASY_RASR = H**（Huang 约束）在同一套 4x4x1 数据上重做。
若 RASR=H 后仍有 < -0.05 THz 的近 Gamma 负频，下一步先用 ENCUT=540 重算平衡帧（单帧）
判断残余应力是否为主因，再决定 S4 是否改设置重算。
（注：datasets/MnIn2Se4_raw 的 3x3x3 / 189 原子数据是 pheasy 自带测试数据集，DFT 设置不明，
不能用于本材料结果。）
