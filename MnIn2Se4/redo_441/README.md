# MnIn₂Se₄ 按 Mn₂In₂Se₅ 同一协议重算（AutoZT kl-dft-cpu，4×4×1 换基矢超胞）

## 为什么要重算

`MnIn2Se4/` 现有的力常数来自 pheasy 官方测试数据集：DFT 设置不明（是否加 U、是否自旋极化、是否 D3 都不知道），
3×3×3 菱方超胞的安全截断只有约 5.2 Å（跨层三阶力常数被切掉，κ_zz 随截断 0.5–4.0 乱变）。
它和 Mn₂In₂Se₅（PBE-D3 + U(Mn)=4 + FM，144 原子，截断 6.51 Å）不是同一套计算，两个材料没法直接比，
也没法把差别归到材料本身。

## 给执行 AI 的指令

**整体照抄 [`../../protocol/kl-dft-cpu_441_Mn2In2Se5_指令.md`](../../protocol/kl-dft-cpu_441_Mn2In2Se5_指令.md)**，
只改下表这些地方。AutoZT 用当前 master（已含 [0105]–[0107]：自旋/U 继承、保原胞对称化、力解析修复、OOM 自动加内存）。
铁律照旧：`rerun`、`clean`、`-f`、`-y` 逐条请示；不自己写监控循环，用 `autozt ... monitor -d`。

S1–S3 已完成、S4 输入已生成（**计算未提交**），归档在 [`dft/`](dft/)：

- `dft_summary.txt` —— S1 末态最大力 / S2 磁矩与**半金属判定** / S3 作废说明 / S4 输入核对表与内存配置
- `s1_std_opt/`、`s2_static/`、`s3_nac/` —— 输入（INCAR/POSCAR/KPOINTS/submit.sh）、结构（CONTCAR）、能量（OSZICAR）
- `s4_disp_inputs/` —— SPOSCAR（112 原子 4×4×1）、位移帧 INCAR/KPOINTS/submit.sh 样例

按仓库 `.gitignore` 约定，原始 `OUTCAR` 不入库（可从集群重取）。
**`s2_static/EIGENVAL` 例外保留**（用 `git add -f`）：它是"半金属 vs 绝缘体"判定的直接证据。

**关键结果**：
- **S1 ✅** max|F| = 0.00064 eV/Å，R-3m、7 原子，a=b=4.0738 Å、c=16.2213 Å。
- **S2 ⚠️ 补偿型半金属**：磁矩 4.9844 = 5 − 1/64；加权电子数 up/down = 33.9922 / 29.0078。
  **两个自旋通道都有口袋**：自旋向上价带顶 3.9945 是空穴口袋（8 个 k 点占据 0.91–0.99，合计少 1/128），
  由 Γ 点自旋向上（带34=带35=3.9371 简并对）与自旋向下（带30=3.8039）两个电子口袋各 1/128 补偿，
  跨自旋交叠 ≈ 0.19 eV。Mn₂In₂Se₅ 完全同构（up/down 45.9922/36.0078，跨自旋交叠 ≈ 0.13 eV）。
  **不报带隙**，统一写"PBE-D3 + U(4 eV) + FM 下为半金属"。真实样品大概率半导体，那是 DFT+U 低估带隙
  外加 FM 假设造成的，需 HSE/AFM 另算才可下结论（κ_L 不需要）。
- **S3 ❌ 整段作废**：ε∞ 全等于 1、压电张量为零、Born 电荷为**负**（Mn −0.94、In −0.62，阳离子应为正）——
  LEPSILON 线性响应根本没算出来（每步 `E=0, ncg=0`），根因正是 S2 的 Γ 点占据重排违反 DFPT 前提。
  **不影响主线**（S6 的 `NAC=off`，S5 不用介电张量）；若将来开 NAC 必须先修这一步。
- **S4 待提交**：46 帧、SPOSCAR 112 原子、KPOINTS 2 2 2、MAGMOM 16*5 96*0 全部核对通过；
  但 `--mem` 在本集群无效（`RealMemory=1`，写了会被拒），OOM 风险来自核数：需把
  `--ntasks-per-node` 由 32 提到 **96**（对齐 Mn₂In₂Se₅ S4；其 144 原子实测峰值 86–173 GB）。
